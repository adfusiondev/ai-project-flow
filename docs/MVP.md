# AI Project Flow — MVP

## MVP Goal

The MVP should provide a clear, structured, and reusable documentation experience that teaches the complete software project lifecycle step by step.

The first version should help the project owner understand what to do at each stage, why each stage matters, which files are involved, which terminal commands are useful, and which AI prompts can be reused.

## MVP Scope

The first version of AI Project Flow will include:

- Clear explanations of the main software project lifecycle stages.
- Documentation of important project files and their purposes.
- Real examples of project files.
- Terminal commands with simple explanations.
- Ready-to-use AI prompts for common project tasks.
- Copyable code blocks and reference content.
- A documentation-style navigation experience for browsing the content.

## Out of Scope

The following features are intentionally excluded from the current MVP:

- Interactive project setup wizard.
- Automatic project file generation.
- Downloadable project starter packs.
- User accounts or authentication.
- Backend services.
- Database integration.
- Project synchronization across devices.
- Advanced project templates.
- Automated IDE or AI agent integrations.

## MVP Success Criteria

The MVP will be considered successful when:

- The main software project lifecycle stages are documented clearly.
- Important project files are explained with practical examples.
- Terminal commands are presented with simple explanations.
- Reusable AI prompts are available for the main project stages.
- Code blocks and reference content can be copied easily.
- The documentation can be browsed through a clear and consistent navigation structure.
- The content remains understandable without relying on previous AI conversation history.
- The project can be opened in another IDE or AI coding environment and still be understandable from its repository files.
