This section explains the main stages of a software project lifecycle that is built with the help of AI coding agents.

The lifecycle is organized so each stage has a clear purpose, produces the artifacts the next stage needs, and can be verified before work moves forward.

## The lifecycle flow

```text
Idea and Discovery
↓
Project Context
↓
MVP Definition
↓
Requirements
↓
Architecture
↓
Implementation Planning
↓
Skills and Agent Instructions
↓
Implementation
↓
Verification and Testing
↓
Project Status Updates
↓
Change Documentation
↓
Handoff and Portability
```

## The stages

- [Idea and Discovery](/lifecycle/idea-and-discovery/) — clarify what you are building and why.
- [Project Context](/lifecycle/project-context/) — record the project's purpose, user, scope, and rules.
- [MVP Definition](/lifecycle/mvp-definition/) — define the smallest useful first version.
- [Requirements](/lifecycle/requirements/) — convert the MVP into verifiable requirements.
- [Architecture](/lifecycle/architecture/) — choose the simplest technical approach that supports the MVP.
- [Implementation Planning](/lifecycle/implementation-planning/) — break the work into verifiable phases.
- [Skills and Agent Instructions](/lifecycle/skills-and-agent-instructions/) — prepare reusable workflows and rules for AI agents.
- [Implementation](/lifecycle/implementation/) — build the project phase by phase.
- [Verification and Testing](/lifecycle/verification-and-testing/) — confirm the work meets its acceptance criteria.
- [Project Status Updates](/lifecycle/project-status-updates/) — keep the project state visible and current.
- [Change Documentation](/lifecycle/change-documentation/) — record meaningful changes and decisions.
- [Handoff and Portability](/lifecycle/handoff-and-portability/) — make the project continueable in another environment.

## How stages relate to files

Most stages produce or update a specific project file. The [Project Files](/files/overview/) section documents each file and its purpose, and the [Prompts](/prompts/overview/) section provides reusable prompts for the main tasks.
