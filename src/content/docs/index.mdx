Welcome to **AI Project Flow**.

This documentation is a personal learning and reusable reference for the complete lifecycle of building software projects with AI coding agents. It documents the stages, files, commands, prompts, skills, verification practices, and handoff processes used during development so they can be understood and reused across different IDEs and AI agents.

## What this site covers

- **Project Lifecycle** — the main stages from idea to handoff.
- **Project Files** — the purpose of the important project files.
- **Skills** — reusable workflows for AI coding agents.
- **Commands** — terminal commands with explanations.
- **Prompts** — reusable AI prompts for common project tasks.
- **Verification** — how to confirm work is complete.
- **Handoff** — making a project portable between environments.
- **Reference** — supporting reference content.

## How to use this documentation

Start with the **Project Lifecycle** section to understand the order of work, then follow each section in sequence. Commands, prompts, and file examples are presented in copyable blocks.

## Quick start

1. Read the [Project Lifecycle](/lifecycle/overview/) section to understand the stages.
2. Open the [Project Files](/files/overview/) section to learn what each repository file does.
3. Use the [Commands](/commands/overview/) section whenever a terminal command needs explanation.
4. Copy reusable [Prompts](/prompts/overview/) when you start a new project task.
5. Follow the [Verification](/verification/overview/) guidance before marking work complete.
6. Use the [Handoff](/handoff/overview/) section when moving a project between environments.

## Run this project

```bash
npm install
npm run dev
```

The development server runs at `http://localhost:4321`.

Build the static site:

```bash
npm run build
```

## Repository as the source of truth

This website documents its own repository. Every page in this site refers to real files, real commands, and real workflows used in this project, so the documentation and the codebase can always be compared against each other.
