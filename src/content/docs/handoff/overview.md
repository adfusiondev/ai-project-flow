This section explains how to prepare a project so it can continue in another IDE or AI coding agent without requiring previous conversation history.

## The goal of a handoff

A receiving agent should be able to determine, from the repository alone:

- What the project is.
- How to run it.
- What is complete.
- What remains.
- What decisions were made.
- What the next step is.
