## Purpose

The MVP Planning skill is used to define the smallest useful first version of a software project.

## Rules

- Define the MVP goal clearly.
- Separate must-have features from future ideas.
- Keep the MVP small, useful, and testable.
- Do not add features only because they may be useful later.
- Define explicit out-of-scope items.
- Define measurable success criteria.

## Output

Create or update `docs/MVP.md` with:

- MVP Goal.
- MVP Scope.
- Out of Scope.
- MVP Success Criteria.

## Quality gate

The MVP is ready when:

- The core value is clear.
- The scope is limited.
- Future features are separated.
- Success criteria can be checked.
