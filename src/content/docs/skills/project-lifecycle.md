## Purpose

The Project Lifecycle skill guides a software project from initial idea through planning, implementation, verification, documentation, and handoff. It acts as the main orchestration workflow for AI-assisted software projects.

## When to use it

Use this skill when:

- Starting a new software project.
- Structuring an unclear project idea.
- Preparing a project before implementation.
- Continuing a partially completed project.
- Moving a project between IDEs or AI coding agents.
- Reconstructing project context after conversation history is unavailable.
- Reviewing whether a project is ready for implementation.

## Operating modes

- **Greenfield mode** — the project is new or mostly empty; run the default flow from idea through handoff.
- The flow mirrors the [Project Lifecycle](/lifecycle/overview/) section of this site.
