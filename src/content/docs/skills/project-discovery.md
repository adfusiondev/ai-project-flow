## Purpose

The Project Discovery skill is used to understand and clarify a software project idea before defining the MVP, requirements, architecture, or implementation plan. The goal is to reduce assumptions and create enough shared understanding to document the project correctly.

## When to use it

Use this skill when:

- Starting a new project.
- The project idea is vague or incomplete.
- Important product decisions are still unknown.
- The user asks for planning before implementation.
- Existing documentation does not clearly explain the project purpose.
- A project is being recovered and its original intent is unclear.

## Core rule

Do not begin implementation during discovery. Discovery exists to understand the project before deciding how to build it.

## What to clarify

- Project purpose — what is being built and why.
- Primary user — who will use it.
- Product form — website, application, API, CLI, or other.
- Platform — browser, desktop, mobile, cloud, or local.
- Core workflow — the main user flow.
