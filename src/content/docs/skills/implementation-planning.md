## Purpose

The Implementation Planning skill is used to convert requirements and architecture into clear implementation phases.

## Rules

- Break the project into meaningful phases.
- Keep each phase focused.
- Define acceptance criteria for every phase.
- Define verification steps.
- Do not mix future scope into the current plan.
- Keep phase status visible.

## Output

Create or update `PLAN.md`.

Each phase should include:

- Objective.
- Scope.
- Tasks.
- Acceptance Criteria.
- Verification.
- Status.

## Quality gate

The plan is ready when:

- Phases are clear and ordered.
- Each phase can be verified.
- The current phase is identifiable.
- The next step is explicit.
