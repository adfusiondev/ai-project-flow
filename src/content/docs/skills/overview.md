This section documents the reusable skills used to guide project work across different IDEs and AI coding agents.

Each skill page explains what the skill is for, when to use it, what workflow it defines, and how to know when the task is complete.

## The skills

- [Project Lifecycle](/skills/project-lifecycle/) — the main orchestration workflow from idea to handoff.
- [Project Discovery](/skills/project-discovery/) — clarify a project idea before planning.
- [MVP Planning](/skills/mvp-planning/) — define the smallest useful first version.
- [Requirements](/skills/requirements/) — convert the MVP into verifiable requirements.
- [Architecture](/skills/architecture/) — choose the simplest technical approach.
- [Implementation Planning](/skills/implementation-planning/) — break work into verifiable phases.
- [Project Documentation](/skills/project-documentation/) — keep documentation synchronized with the repository.
- [Project Status](/skills/project-status/) — keep the current project state visible.
- [Verification](/skills/verification/) — confirm work satisfies documented criteria.
- [Handoff](/skills/handoff/) — prepare a project for another environment.
- [UI Implementation](/skills/ui-implementation/) — implement user interface elements consistently.

## Where skills live

Skills live under `skills/` in the repository, one directory per skill, each containing a `SKILL.md`. See [SKILL.md](/files/skill/) for what a skill file contains.
