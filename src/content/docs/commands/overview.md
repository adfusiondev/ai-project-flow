This section presents the terminal commands used in the AI Project Flow workflow with explanations of what they do and when to use them.

Each command page explains:

- What the command does.
- What its important parts mean.
- When the command should be used.
- What result to expect.
- Whether it changes files or only reads information.

## The commands

### Project setup and development

- [npm install](/commands/npm-install/) — install the project dependencies.
- [npm run dev](/commands/npm-run-dev/) — start the local development server.
- [npm run build](/commands/npm-run-build/) — build the static site.
- [npm run preview](/commands/npm-run-preview/) — preview the built site locally.

### Version control

- [git status](/commands/git-status/) — show the state of the working tree.
- [git add](/commands/git-add/) — stage changes for commit.
- [git commit](/commands/git-commit/) — record staged changes.
- [git log](/commands/git-log/) — show commit history.
- [git diff](/commands/git-diff/) — show changes between states.
