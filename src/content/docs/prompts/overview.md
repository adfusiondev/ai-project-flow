This section provides reusable AI prompts for the main project lifecycle tasks. Each prompt is written so it can be reused with different coding agents where practical, without depending on one specific AI tool.

Each prompt page explains:

- When to use the prompt.
- The reusable prompt itself.
- What output to expect.
- Notes on using it.

## The prompts

- [Resume a Project](/prompts/resume-project/) — continue a project from its repository state.
- [Project Discovery](/prompts/project-discovery/) — clarify an idea before planning.
- [Project Context](/prompts/project-context/) — document the project's permanent context.
- [MVP Planning](/prompts/mvp-planning/) — define the smallest useful first version.
- [Requirements](/prompts/requirements/) — convert the MVP into requirements.
- [Architecture](/prompts/architecture/) — choose the simplest technical approach.
- [Implementation Planning](/prompts/implementation-planning/) — break the work into phases.
- [Implementation](/prompts/implementation/) — build a phase of the project.
- [Verification](/prompts/verification/) — verify work before marking it complete.
- [Handoff](/prompts/handoff/) — prepare the project for another environment.

## How to use these prompts

Copy the prompt into your AI coding agent, replace the placeholders with your project details, and follow the prompt's instructions. Prompts assume the agent has access to the project repository.
