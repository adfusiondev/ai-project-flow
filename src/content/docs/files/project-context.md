## What it is

`PROJECT_CONTEXT.md` is the permanent record of what the project is, who it is for, what the current MVP is, and what rules the project follows.

## Why it exists

Conversation history is not a reliable source of truth. This file makes the project self-explaining to any human or AI agent that opens the repository.

## When it should be created

At the start of the project, immediately after the discovery stage is complete.

## When it should be updated

- After a meaningful change in purpose, scope, or MVP.
- When important rules or constraints change.
- When the current product form changes.

## Practical example

This repository's own `PROJECT_CONTEXT.md` explains:

- The project purpose — a learning and reference project for AI-assisted software development.
- The primary user — the project owner.
- The current product form — a documentation website.
- The current MVP and its contents.
- Future scope, separated from the MVP.
- Languages and portability goals.
- Core project rules.
