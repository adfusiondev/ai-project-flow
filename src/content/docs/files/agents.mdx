## Purpose

Because agents do not share conversation history, this file makes every agent follow the same reading order, working rules, and verification sequence.

## When to use it

**Required** for Standard and Advanced projects; **optional** for Small.

- **Create** — before implementation begins.
- **Update** — when working rules, the reading order, or the verification rule change.
- **Skip** — when you work alone and use no AI coding agents.

## Required inputs

- The project purpose and supported environments.
- The required reading order.
- Core working rules and the verification sequence.

## Reads from and feeds into

- Reads from `PROJECT_CONTEXT.md`, `PROJECT_STATUS.md`, `PLAN.md`, and `HANDOFF.md`.
- Feeds into every agent session and the reusable `SKILL.md` files.
