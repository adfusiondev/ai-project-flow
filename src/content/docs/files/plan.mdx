## Purpose

An ordered, phase-by-phase roadmap any agent can follow — so a future agent without conversation history knows what is done and what comes next.

## When to use it

**Required** for Standard and Advanced projects; **optional** for Small.

- **Create** — after requirements and architecture, before implementation.
- **Update** — after a phase completes, when the plan changes, or when the next step changes.
- **Skip** — when the project is a single small task.

## Required inputs

- The goal and scope of each phase.
- Tasks, acceptance criteria, and verification for each phase.
- The current status of each phase.

## Reads from and feeds into

- Reads from `PROJECT_CONTEXT.md`, `docs/MVP.md`, `docs/REQUIREMENTS.md`, `docs/ARCHITECTURE.md`, and `docs/DECISIONS.md`.
- Feeds into `PROJECT_STATUS.md`, `CHANGELOG.md`, and `HANDOFF.md`.
