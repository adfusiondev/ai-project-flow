A `SKILL.md` file (one per directory under `skills/`) defines a reusable workflow for a specific project task, making it portable across agents and environments.

## Purpose

Skills turn repeatable tasks — discovery, MVP planning, verification, handoff — into consistent, specialized workflows any agent can follow.

## When to use it

**Required** for Advanced projects; **optional** for Standard; **not used** for Small.

- **Create** — when a task will repeat across projects, or an agent should follow a specific workflow.
- **Update** — when the workflow or its inputs and outputs change.
- **Skip** — when the workflow is unique to one project and unlikely to be reused.

## Required inputs

- The task's purpose and when to use it.
- The workflow steps and rules.
- Expected output files and a quality gate.

## Reads from and feeds into

- Reads from `AGENTS.md` (working rules) and `PROJECT_CONTEXT.md`.
- Feeds into the work agents perform and the Skills section documentation.
