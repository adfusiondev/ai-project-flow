## Purpose

A quick answer to "where is the project?" — so any agent or human can pick up the project without needing the conversation history.

## When to use it

- **Create** — as soon as there is meaningful work to report.
- **Update** — after a phase is completed, after meaningful changes, or when the next recommended step changes.

## Required inputs

- Current phase and overall status.
- Completed, in-progress, and pending work.
- Known issues and blockers.
- The single next recommended step.

## Reads from and feeds into

- Reads from `PROJECT_CONTEXT.md`, `PLAN.md`, `CHANGELOG.md`, `HANDOFF.md`, and recent git history.
- Feeds into the next session's resume prompt and into `HANDOFF.md`.
