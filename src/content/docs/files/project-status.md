## What it is

`PROJECT_STATUS.md` records the current state of the project: the current phase, overall status, completed work, in-progress work, pending work, known issues, blockers, and the next recommended step.

## Why it exists

Any agent or human opening the repository should be able to quickly determine where the project is. The status file makes the project self-explaining without requiring conversation history.

## When it should be created

As soon as there is meaningful work to report.

## When it should be updated

- After a phase is completed.
- After meaningful changes.
- When the next recommended step changes.

## What it should include

- Current Phase.
- Overall Status.
- Completed.
- In Progress.
- Pending.
- Known Issues.
- Blockers.
- Next Recommended Step.
