## Purpose

The compact summary that makes the project transferable: current phase, what is done, how to run it, and the next step.

## When to use it

**Required** for Advanced projects; **optional** for Standard; **not used** for Small.

- **Create** — before the first handoff to another environment.
- **Update** — when the phase, decisions, or next step change.
- **Recover** — when resuming in a new environment, reconstruct it from the repository state.
- **Skip** — when the project stays in one environment.

## Required inputs

- Project name, type, and current phase.
- Completed work, known issues, and the next recommended step.
- How to run the project.

## Reads from and feeds into

- Reads from `PROJECT_CONTEXT.md`, `PROJECT_STATUS.md`, `PLAN.md`, `CHANGELOG.md`, and `docs/DECISIONS.md`.
- Feeds into the receiving environment's first session and its `PROJECT_STATUS.md`.
