Pick a size to see the files for that mode in the recommended order. The first file is highlighted — generate its prompt, then work down the list.

<div id="project-start" />

## What to do next

- Create the highlighted first file first — everything else builds on it.
- Work through the list in order; each row's badge shows whether the file is **Required**, **Recommended**, or **Optional** for the chosen size.
- Use the generate link on each row, or open the [Prompt Generator](/tools/prompt-generator/) directly.
