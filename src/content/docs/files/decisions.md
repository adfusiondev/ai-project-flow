## What it is

`docs/DECISIONS.md` records important project decisions and the reasoning behind each one.

## Why it exists

Its purpose is to prevent important choices from being lost, silently reversed, or re-decided without understanding the original context.

## When it should be created

Early in the project, as soon as the first important decision is made.

## When it should be updated

- Whenever an important decision is made.
- Whenever an existing decision is superseded or rejected.

## What each decision should include

- The decision.
- Why it was made.
- Alternatives considered where relevant.
- Current status (Proposed, Accepted, Superseded, or Rejected).

## Practical example

This repository's `docs/DECISIONS.md` records decisions such as:

- DEC-001 — Documentation website first.
- DEC-003 — Repository as source of truth.
- DEC-006 — No backend in the current MVP.
- DEC-009 — Arabic and English readiness.
- DEC-010 — Astro + Starlight selected.
