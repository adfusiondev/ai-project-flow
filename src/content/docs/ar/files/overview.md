ملفات المشروع هي مجموعة صغيرة من ملفات Markdown تحافظ على سهولة فهم المشروع المدعوم بالذكاء الاصطناعي وقابليته للنقل واستقلاله عن سجل المحادثة.

## ابدأ مشروعًا جديدًا

إذا كنت تبدأ مشروعًا، فاختر حجمًا واتبع التسلسل الموصى به:

## الملفات

توضح كل صفحة ملف ما هو الملف، ومتى تنشئه، ومتى تحدّثه، وكيف تولّد المطالبة الخاصة به.

| الملف | الغرض |
| --- | --- |
| [PROJECT_CONTEXT.md](/ar/files/project-context/) | السياق الدائم للمشروع وقواعده — دائمًا أول ملف. |
| [docs/MVP.md](/ar/files/mvp/) | أصغر نسخة مفيدة أولى. |
| [docs/REQUIREMENTS.md](/ar/files/requirements/) | ما يجب أن يفعله المشروع وكيف. |
| [docs/ARCHITECTURE.md](/ar/files/architecture/) | الشكل التقني للمشروع. |
| [docs/DECISIONS.md](/ar/files/decisions/) | الخيارات المهمة ومبرراتها. |
| [PLAN.md](/ar/files/plan/) | مراحل التنفيذ. |
| [PROJECT_STATUS.md](/ar/files/project-status/) | الحالة الراهنة للمشروع والخطوة التالية. |
| [AGENTS.md](/ar/files/agents/) | قواعد عمل وكلاء الذكاء الاصطناعي. |
| [CHANGELOG.md](/ar/files/changelog/) | سجل التغييرات المهمة. |
| [HANDOFF.md](/ar/files/handoff/) | الحد الأدنى من المعلومات اللازمة لاستمرار المشروع. |
| [SKILL.md](/ar/files/skill/) | سير عمل قابلة لإعادة الاستخدام لمهمة محددة. |

## كيف يتناسب مولّد المطالبات

يحوّل [مولّد المطالبات](/ar/tools/prompt-generator/) أي مهمة ملف إلى مطالبة قابلة لإعادة الاستخدام والنسخ: اختر الحجم، والملف المستهدف، والإجراء (إنشاء أو مراجعة أو تحديث أو استعادة) ثم انسخ النتيجة. استخدمه من صفحة البدء، أو من صفحة كل ملف، أو مباشرة.

## من أين تبدأ

ابدأ بـ [PROJECT_CONTEXT.md](/ar/files/project-context/) — كل ملف لاحق يعتمد عليه.
