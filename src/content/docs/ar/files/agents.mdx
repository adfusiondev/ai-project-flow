## الغرض

لأن الوكلاء لا يتشاركون سجل المحادثة، يجعل هذا الملف كل وكيل يتبع نفس ترتيب القراءة وقواعد العمل وتسلسل التحقق.

## متى تستخدمه

**مطلوب** للمشاريع القياسية والمتقدمة؛ **اختياري** للصغيرة.

- **إنشاء** — قبل بدء التنفيذ.
- **تحديث** — عندما تتغير قواعد العمل أو ترتيب القراءة أو قاعدة التحقق.
- **تخطٍّ** — عندما تعمل وحدك دون استخدام وكلاء ترميز بالذكاء الاصطناعي.

## المدخلات المطلوبة

- غرض المشروع والبيئات المدعومة.
- ترتيب القراءة المطلوب.
- قواعد العمل الأساسية وتسلسل التحقق.

## يقرأ من ويُغذّي

- يقرأ من `PROJECT_CONTEXT.md` و`PROJECT_STATUS.md` و`PLAN.md` و`HANDOFF.md`.
- يغذّي كل جلسة وكيل وملفات `SKILL.md` القابلة لإعادة الاستخدام.
