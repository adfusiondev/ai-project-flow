## ما هو الملف

يحدد `AGENTS.md` قواعد العمل الافتراضية لوكلاء الذكاء الاصطناعي العاملين على المشروع.

## لماذا يوجد

لا يتشارك وكلاء الذكاء الاصطناعي سجل المحادثة. هذا الملف هو العقد القابل للنقل الذي يجعل كل وكيل يتبع قواعد التخطيط والتنفيذ والتحقق نفسها.

## متى يجب إنشاؤه

قبل بدء التنفيذ، ليعمل الوكلاء العاملون على المشروع وفق القواعد نفسها.

## متى يجب تحديثه

- عندما تتغير قواعد العمل.
- عندما يتغير ترتيب القراءة أو وثائق المشروع.
- عندما تتغير قاعدة التحقق.

## ما الذي يجب أن يحتويه

- غرض المشروع وبيئة العمل.
- ترتيب القراءة المطلوب قبل إجراء التغييرات.
- قواعد العمل الأساسية.
- قائمة "قبل التنفيذ".
- قواعد "أثناء التنفيذ".
- قاعدة التحقق والتسلسل المتوقع.

## مثال عملي

يتطلب `AGENTS.md` الخاص بهذا المستودع من الوكلاء قراءة `PROJECT_CONTEXT.md` و`PROJECT_STATUS.md` و`PLAN.md` و`HANDOFF.md` والملفات ذات الصلة في `docs/` قبل إجراء تغييرات ذات معنى، واتباع التسلسل: التخطيط ← التنفيذ ← التشغيل ← الفحص ← الاختبار ← الإصلاح ← التحقق ← التحديث ← التسجيل ← نقطة التوقف.

القسم ذو الصلة: [مرحلة المهارات وتوجيهات الوكلاء](/ar/lifecycle/skills-and-agent-instructions/).
