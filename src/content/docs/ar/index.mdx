مرحباً بك في **AI Project Flow**.

هذه الوثائق مرجع شخصي قابل لإعادة الاستخدام يغطي دورة حياة بناء مشاريع البرمجيات كاملةً باستخدام وكلاء الذكاء الاصطناعي. توثّق هذه الصفحات المراحل والملفات والأوامر والمطالبات والمهارات وممارسات التحقق والتسليم المستخدمة أثناء التطوير، لتُفهم وتُعاد الاستفادة منها عبر بيئات وأدوات متعددة.

## محتوى هذا الموقع

- **دورة حياة المشروع** — المراحل الرئيسية من الفكرة حتى التسليم.
- **ملفات المشروع** — الغرض من الملفات الأساسية في المشروع.
- **المهارات** — سير عمل قابلة لإعادة الاستخدام لوكلاء الذكاء الاصطناعي.
- **الأوامر** — أوامر الطرفية مع شرح لكل منها.
- **المطالبات (Prompts)** — مطالبات جاهزة لأشيع مهام المشروع.
- **التحقق من الصحة** — كيفية التأكد من اكتمال العمل فعلاً.
- **التسليم** — جعل المشروع قابلاً للنقل بين البيئات.
- **المراجع** — محتوى مرجعي داعم.

## كيفية استخدام هذه الوثائق

ابدأ بقسم **دورة حياة المشروع** لفهم ترتيب العمل، ثم تابع كل قسم على التوالي. الأوامر والمطالبات وأمثلة الملفات مقدَّمة في كتل قابلة للنسخ.

## البداية السريعة

1. اقرأ قسم [دورة حياة المشروع](/ar/lifecycle/overview/) لفهم المراحل.
2. افتح قسم [ملفات المشروع](/ar/files/overview/) لتتعرف على غرض كل ملف في المستودع.
3. ارجع إلى قسم [الأوامر](/ar/commands/overview/) عند الحاجة لشرح أي أمر في الطرفية.
4. انسخ [المطالبات](/ar/prompts/overview/) الجاهزة عند بدء مهمة جديدة.
5. اتبع إرشادات [التحقق](/ar/verification/overview/) قبل الإعلان عن اكتمال العمل.
6. استعن بقسم [التسليم](/ar/handoff/overview/) عند نقل المشروع بين البيئات.

## تشغيل هذا المشروع

```bash
npm install
npm run dev
```

يعمل خادم التطوير على العنوان `http://localhost:4321`.

لبناء الموقع الثابت:

```bash
npm run build
```

## المستودع مصدر الحقيقة

يوثّق هذا الموقع مستودعه بنفسه. كل صفحة في الموقع تشير إلى ملفات حقيقية وأوامر حقيقية وسير عمل فعلية مستخدمة في هذا المشروع، مما يتيح مقارنة الوثائق مع قاعدة الكود في أي وقت.
