مرحباً بك في **AI Project Flow**.

هذه الوثائق مرجع شخصي قابل لإعادة الاستخدام لدورة بناء مشاريع البرمجيات باستخدام وكلاء الذكاء الاصطناعي. توثّق هذه الصفحات المراحل والملفات والأوامر والطلبات والمهارات وممارسات التحقق والتسليم المستخدمة أثناء التطوير، لتُفهم وتُعاد الاستفادة منها عبر بيئات وأدوات مختلفة.

> ملاحظة: المحتوى الكامل لهذه الوثائق مكتوب باللغة الإنجليزية حالياً. هذه الصفحة تهدف إلى إثبات جاهزية التخطيط للاتجاه من اليمين إلى اليسار.

## تشغيل هذا المشروع

```bash
npm install
npm run dev
```

يعمل خادم التطوير على العنوان `http://localhost:4321`.

لبناء الموقع الثابت:

```bash
npm run build
```
