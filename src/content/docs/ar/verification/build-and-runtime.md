---
title: فحوصات البناء والتشغيل

---

تؤكد فحوصات البناء والتشغيل أن التنفيذ يُترجم فعلاً ويعمل، وليس فقط أنه يبدو صحيحاً في المصدر.

## فحص البناء

شغّل البناء وتأكد من اكتماله:

```bash
npm run build
```

ما الذي يجب الانتباه إليه:

- اكتمال البناء دون أخطاء.
- الإبلاغ عن العدد المتوقع من الصفحات.
- فهم أي تحذيرات وتوثيقها (مثل تحذير sitemap الذي يظهر حتى يُعرف نطاق النشر).

## فحص التشغيل

شغّل خادم التطوير وتأكد من استجابة المسارات:

```bash
npm run dev
```

ما الذي يجب الانتباه إليه:

- يبدأ الخادم ويطبع رابطاً محلياً.
- تُحمَّل المسارات الرئيسية وتُعيد HTTP 200.
- يظهر المحتوى والتنقل والأنماط المشتركة كما هو متوقع.
- لا تظهر أخطاء تشغيل حرجة في وحدة تحكم المتصفح.

## فحص المعاينة

بعد بناء إنتاجي، تحقق من المخرجات المبنية محلياً:

```bash
npm run preview
```

## ما يُعد نجاحاً

- ينجح البناء.
- تُحمَّل المسارات بشكل صحيح.
- لا توجد أخطاء تشغيل حرجة.
- تُوثّق أي تحذيرات أو قيود.

الأوامر ذات الصلة: [npm run build](/ar/commands/npm-run-build/)، [npm run dev](/ar/commands/npm-run-dev/)، [npm run preview](/ar/commands/npm-run-preview/).
