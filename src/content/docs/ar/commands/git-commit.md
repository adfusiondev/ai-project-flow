---
title: git commit
description: تسجيل التغييرات المهيَّأة في تاريخ المستودع.
---

```bash
git commit -m "message"
```

## ما يفعله الأمر

يسجّل التغييرات المهيَّأة كإدخال دائم في سجل التزامات المشروع.

## الأجزاء المهمة

- `git` — أمر التحكم بالإصدارات.
- `commit` — ينشئ الالتزام من التغييرات المهيَّأة.
- `-m "message"` — رسالة الالتزام التي تصف التغيير.

## متى يُستخدم

- بعد تهيئة تغييرات ذات معنى تمت مراجعتها.
- عندما ينبغي الحفاظ على نقطة توقف في التاريخ.

## النتيجة المتوقعة

يُنشأ التزام جديد. سيظهر في السجل عبر `git log`.

## هل يُعدّل الملفات؟

يسجّل التغييرات في تاريخ Git لكنه لا يعدّل محتوى المشروع. لا تلتزم إلا بالتغييرات التي تنوي الإبقاء عليها.
