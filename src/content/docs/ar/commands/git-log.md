---
title: git log
description: عرض سجل التزامات المستودع.
---

```bash
git log --oneline
```

## ما يفعله الأمر

يسرد التزامات المستودع، الأحدث أولاً.

## الأجزاء المهمة

- `git` — أمر التحكم بالإصدارات.
- `log` — يعرض سجل الالتزامات.
- `--oneline` — يعرض كل التزام في سطر واحد مدمج.

## متى يُستخدم

- لمراجعة ما أُنجز في المشروع.
- للعثور على آخر نقطة توقف مكتملة قبل متابعة العمل.

## النتيجة المتوقعة

قائمة زمنية بالالتزامات مع رسائلها ومعرّفاتها، على سبيل المثال:

```text
0c77943 feat: establish AI Project Flow documentation MVP foundation
```

## هل يُعدّل الملفات؟

لا — يقرأ المعلومات فقط.
