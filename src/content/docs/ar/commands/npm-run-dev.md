---
title: npm run dev
description: تشغيل خادم التطوير المحلي.
---

```bash
npm run dev
```

## ما يفعله الأمر

يشغّل خادم تطوير Astro مع إعادة التحميل الفوري، بحيث تظهر تغييرات المحتوى والأنماط مباشرة في المتصفح.

## الأجزاء المهمة

- `npm run` — يشغّل نصاً مُعرّفاً في `package.json`.
- `dev` — اسم النص لخادم التطوير.

## متى يُستخدم

- أثناء التطوير، عندما تريد مشاهدة التغييرات مباشرة.
- عندما تحتاج إلى فحص المسارات والمحتوى في المتصفح.

## النتيجة المتوقعة

يطبع الخادم رابطاً محلياً، افتراضياً `http://localhost:4321`. افتحه في متصفح لعرض الموقع.

## هل يُعدّل الملفات؟

لا — يقرأ المشروع ويخدمه محلياً فقط.
