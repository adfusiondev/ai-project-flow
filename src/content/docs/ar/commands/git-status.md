---
title: git status
description: عرض الحالة الحالية لشجرة العمل.
---

```bash
git status
```

## ما يفعله الأمر

يعرض الملفات التي تغيّرت، والتي هُيّئت للالتزام، والتي لا يتبعها Git (untracked).

## الأجزاء المهمة

- `git` — أمر التحكم بالإصدارات.
- `status` — يعرض حالة شجرة العمل ومنطقة التهيئة.

## متى يُستخدم

- قبل الالتزام، لمراجعة ما سيُلتزم به.
- للتحقق مما إذا كان المستودع نظيفاً أو لديه تغييرات معلّقة.

## النتيجة المتوقعة

ملخص مثل `nothing to commit, working tree clean` عند عدم وجود تغييرات معلّقة، أو قائمة بالملفات المعدّلة والمهيَّأة وغير المتتبعة.

## هل يُعدّل الملفات؟

لا — يقرأ المعلومات فقط.
