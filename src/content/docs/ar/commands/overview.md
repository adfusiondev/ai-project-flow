يعرض هذا القسم أوامر الطرفية المستخدمة في سير عمل AI Project Flow مع شرح لما تفعله ومتى تُستخدم.

توضّح كل صفحة أمر ما يلي:

- ما يفعله الأمر.
- معنى أجزائه الرئيسية.
- متى يجب استخدام الأمر.
- النتيجة المتوقعة.
- ما إذا كان يُعدّل الملفات أم يقرأ المعلومات فقط.

## الأوامر

### إعداد المشروع والتطوير

- [npm install](/ar/commands/npm-install/) — تثبيت اعتماديات المشروع.
- [npm run dev](/ar/commands/npm-run-dev/) — تشغيل خادم التطوير المحلي.
- [npm run build](/ar/commands/npm-run-build/) — بناء الموقع الثابت.
- [npm run preview](/ar/commands/npm-run-preview/) — معاينة الموقع المبني محلياً.

### التحكم بالإصدارات

- [git status](/ar/commands/git-status/) — عرض حالة شجرة العمل.
- [git add](/ar/commands/git-add/) — إضافة التغييرات إلى منطقة التهيئة.
- [git commit](/ar/commands/git-commit/) — تسجيل التغييرات المهيَّأة.
- [git log](/ar/commands/git-log/) — عرض سجل الالتزامات.
- [git diff](/ar/commands/git-diff/) — عرض الفروق بين الحالات.
