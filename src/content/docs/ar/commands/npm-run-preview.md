---
title: npm run preview
description: معاينة الموقع الثابت المبني محلياً.
---

```bash
npm run preview
```

## ما يفعله الأمر

يخدم مخرجات `npm run build` من `dist/` ليمكنك مراجعة البناء الإنتاجي محلياً قبل النشر.

## الأجزاء المهمة

- `npm run` — يشغّل نصاً مُعرّفاً في `package.json`.
- `preview` — اسم النص لخدمة الموقع المبني.

## متى يُستخدم

- بعد البناء، للتحقق من أن المخرجات الإنتاجية تبدو وتعمل بشكل صحيح.

## النتيجة المتوقعة

رابط محلي يخدم الموقع المبني، مختلف عن خادم التطوير.

## هل يُعدّل الملفات؟

لا — يقرأ `dist/` ويخدمه محلياً فقط.
