---
title: git diff
description: عرض الفروق بين الملفات أو الحالات.
---

```bash
git diff
```

## ما يفعله الأمر

يعرض التغييرات الدقيقة التي أُجريت على الملفات المتتبعة، سطراً بسطر.

## الأجزاء المهمة

- `git` — أمر التحكم بالإصدارات.
- `diff` — يعرض الفروق.
- أضف `--staged` لعرض التغييرات المهيَّأة بالفعل للالتزام.

## متى يُستخدم

- قبل الالتزام، لمراجعة ما تغيّر بدقة.
- للتحقق من أن التغيير يطابق ما كان مقصوداً.

## النتيجة المتوقعة

قائمة سطراً بسطر بالأسطر المحذوفة والمضافة، مع `-` للأسطر المحذوفة و`+` للأسطر المضافة.

## هل يُعدّل الملفات؟

لا — يقرأ المعلومات فقط.
