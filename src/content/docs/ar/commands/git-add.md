---
title: git add
description: إضافة التغييرات إلى منطقة التهيئة ليتمكن الالتزام بها لاحقاً.
---

```bash
git add <file>
```

## ما يفعله الأمر

يضيف الملف أو الملفات المحددة إلى منطقة التهيئة (staging area)، لتحضيرها للالتزام التالي.

## الأجزاء المهمة

- `git` — أمر التحكم بالإصدارات.
- `add` — يهيّئ المسارات المحددة.
- `<file>` — الملف أو المجلد المراد تهيئته؛ استخدم `.` لتهيئة جميع التغييرات.

## متى يُستخدم

- بعد إجراء التغييرات، قبل الالتزام.
- عندما تريد الالتزام بمجموعة محددة من الملفات فقط.

## النتيجة المتوقعة

تظهر الملفات المهيَّأة تحت "Changes to be committed" في `git status`.

## هل يُعدّل الملفات؟

يغيّر حالة التهيئة في Git، لكنه لا يعدّل الملفات الفعلية للمشروع.
