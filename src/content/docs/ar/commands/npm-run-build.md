title: npm run build
description: بناء الموقع الثابت في مجلد dist.
---

```bash
npm run build
```

## ما يفعله الأمر

يبني الموقع الثابت ويكتب المخرجات إلى `dist/`. يجمّع المحتوى، وينشئ فهرس البحث، ويُبلغ عن عدد الصفحات المبنيّة.

## الأجزاء المهمة

- `npm run` — يشغّل نصاً مُعرّفاً في `package.json`.
- `build` — اسم النص للبناء الإنتاجي.

## متى يُستخدم

- قبل النشر أو التوزيع.
- بعد تغييرات كبيرة، للتحقق من أن الموقع ما يزال يُبنى.
- كجزء من سير عمل [التحقق](/ar/verification/build-and-runtime/).

## النتيجة المتوقعة

مجلد `dist/` يحتوي الموقع الثابت المُنشأ. يُبلغ البناء بشيء مثل `10 page(s) built`. تحذير sitemap بشأن غياب رابط `site` متوقع حتى يُعرف نطاق النشر.

## هل يُعدّل الملفات؟

نعم — ينشئ أو يستبدل مجلد المخرجات `dist/`.
