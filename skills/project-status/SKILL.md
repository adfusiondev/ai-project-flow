# Project Status Skill

## Purpose

Use this skill to keep the current project state clear and easy to understand.

## Output

Create or update:

- `PROJECT_STATUS.md`

## The Status Should Include

- Current Phase
- Overall Status
- Completed
- In Progress
- Pending
- Known Issues
- Blockers
- Next Recommended Step

## Rules

- Reflect the actual repository state.
- Do not mark work complete before verification.
- Keep the next step explicit.
- Update status after meaningful project changes.

## Quality Gate

The status is ready when another agent can quickly understand:

- Where the project is now.
- What is finished.
- What remains.
- What should happen next.
