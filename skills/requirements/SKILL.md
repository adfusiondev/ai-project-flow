# Requirements Skill

## Purpose

Use this skill to convert the approved MVP into clear project requirements.

## Rules

- Keep requirements aligned with `docs/MVP.md`.
- Do not introduce future-scope features.
- Separate requirement types clearly.
- Make requirements specific enough to verify later.

## Requirement Types

Use only what the project needs:

- Functional Requirements
- Non-Functional Requirements
- Content Requirements
- Design Requirements
- Localization Requirements
- Portability Requirements
- Security Requirements
- Data Requirements

## Output

Create or update:

- `docs/REQUIREMENTS.md`

## Quality Gate

Requirements are ready when:

- They match the MVP.
- Important behavior is clear.
- Constraints are documented.
- Requirements can later be verified.
