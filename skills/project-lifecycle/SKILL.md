# Project Lifecycle Skill

## Purpose

Use this skill to guide a software project from initial idea through planning, implementation, verification, documentation, and handoff.

This skill acts as the main orchestration workflow for AI-assisted software projects.

The repository should remain the primary source of truth.

---

## Use This Skill When

Use this skill when:

- Starting a new software project.
- Structuring an unclear project idea.
- Preparing a project before implementation.
- Continuing a partially completed project.
- Moving a project between IDEs or AI coding agents.
- Reconstructing project context after conversation history is unavailable.
- Reviewing whether a project is ready for implementation.

---

## Operating Modes

This skill supports two main modes.

### Greenfield Mode

Use when the project is new or mostly empty.

Default flow:

```text
Idea and Discovery
↓
Project Context
↓
MVP Definition
↓
Requirements
↓
Architecture
↓
Implementation Planning
↓
Skills and Agent Instructions
↓
Implementation
↓
Verification and Testing
↓
Project Status Updates
↓
Change Documentation
↓
Handoff and Portability
```
